# Gouvernance des données

Les ressources décrites appartiennent à des auteurs et à une communauté. Le dépôt applique les principes **CARE** (Collective benefit, Authority to control, Responsibility, Ethics) :

| Principe | Application |
|---|---|
| Bénéfice collectif | Catalogue ouvert, code libre (MIT), aucune dépendance propriétaire pour le cœur |
| Autorité de contrôle | Seules les fiches **validées par le comité** sont servies ; le comité garde la main sur le glossaire kabyle |
| Responsabilité | Chaque réponse affiche source, licence et empreinte ; reçu reproductible |
| Éthique | Les licences sont affichées avec chaque résultat ; le système ne copie pas les ressources, il renvoie vers leur source |

## Règles

- Une fiche sans `validated: true` n'est jamais citée.
- La licence de chaque ressource est celle de la fiche ; le système n'en déduit aucune.
- Aucune donnée de question n'est stockée par le cœur.
- Les formes kabyles du glossaire sont ajoutées **uniquement** après relecture humaine.
- Un document en quarantaine est examiné par une personne avant toute réintégration.
